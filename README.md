# Namya Mehta · Portfolio
Live site: https://techyeye98.github.io/

An interactive particle-portrait hero plus hands-on demos of Pocket Ledger, TVora, Zed Flash and Evaluator. Built by hand with HTML, CSS and JavaScript, Three.js for the dot portrait and Motion for animation.

## Run locally
Serve this folder with any static server, for example `python -m http.server 8000`, then open http://localhost:8000. Opening index.html straight from disk will not load the portrait.
